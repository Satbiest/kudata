# Survey Platform Analytics Dashboard

## Overview

**Survey Platform Analytics Dashboard** is an interactive dashboard developed during my **Data Analyst Internship at Kudata.id**.

The dashboard is designed to provide a comprehensive overview of survey performance, user engagement, participation behavior, and payment activities. It transforms survey platform data into meaningful and easy-to-understand insights to support performance monitoring, engagement analysis, and data-driven decision-making.

The dashboard was developed using **Looker Studio** for interactive data visualization and **Microsoft Excel** for data preparation, cleaning, and processing.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Monitor overall survey platform performance.
- Track user growth and survey participation trends.
- Evaluate survey engagement and completion performance.
- Analyze participant achievement against survey targets.
- Understand user demographic characteristics.
- Monitor payment activities and reward distribution.
- Provide stakeholders with an interactive dashboard for easier performance monitoring and analysis.

---

## 📌 Dashboard Structure

The dashboard consists of three main sections:

### 1. Executive Overview

The **Executive Overview** provides a high-level summary of the platform's key performance indicators and overall activity.

Key metrics include:

- Total Users
- Total Surveys
- Total Participation
- Total Payment
- Average Reward
- Fulfillment Rate
- User Growth Trend
- Participation Trend

This section enables stakeholders to quickly understand the overall condition and performance of the survey platform.

---

### 2. Survey Engagement & Performance

The **Survey Engagement & Performance** section focuses on analyzing how users interact with surveys and how effectively surveys achieve their participation targets.

The analysis includes:

- Participant Progress
- Survey Fulfillment Rate
- Reward Distribution
- Survey Duration
- Participant Achievement vs. Target
- Repeat Participation Rate
- Survey Engagement Performance
- Survey Completion Performance

This section helps identify survey participation patterns and provides insights into how effectively each survey attracts and retains participants.

---

### 3. User & Payment Analysis

The **User & Payment Analysis** section provides deeper insights into user characteristics and payment activities within the platform.

User analysis includes:

- User Demographics
- Occupation
- City
- Education Level
- User Distribution

Payment analysis includes:

- Paid Users
- Payment Amount
- Payment Trends
- Reward and Payment Distribution

This section helps stakeholders better understand the platform's user base and monitor payment activities over time.
